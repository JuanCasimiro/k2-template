## Dónde se usa

| Desde la compu | Desde el teléfono | Desde Obsidian |
|----------------|-------------------|----------------|
| Claude Code — todo | Remote Control — la misma sesión | Ver y navegar tus notas |
| Tareas largas y multi-paso | Consultas rápidas, dictar sobre la marcha | Editar archivos a mano |
| Investigación profunda | Guardar algo que pasó recién | Buscar en todo el sistema |

Es el mismo sistema en los tres lados. Los archivos son los mismos.

---

## Primera vez

Abrí Claude Code en esta carpeta y escribí `/k2-onboarding`. Te hace preguntas sobre tu empresa durante unos 20 minutos y configura todo solo.

---

## Referencia rápida de commands

> No hace falta memorizarlos: Claude los aplica solo cuando detecta que hacen falta.

| Command | Qué hace |
|---------|----------|
| `/k2-onboarding` | Configura el sistema para tu empresa |
| `/k2-aprender` | Guarda un aprendizaje importante |
| `/k2-investigar-rol` | Busca mejores prácticas de tu sector |
| `/k2-adaptar` | Le decís cómo querés los entregables |
| `/k2-planificacion` | Planificás un proyecto o área |
| `/k2-nuevo-proyecto` | Creás una nueva área en el sistema |
